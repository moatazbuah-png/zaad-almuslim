# مخطط تطوير زاد المسلم

## الرؤية
زاد المسلم منظومة إسلامية رقمية مجانية للمستخدم، هدفها جمع العبادة والمعرفة والتعليم والأدوات اليومية في تجربة عربية سريعة وموثوقة.

## مبادئ المنتج
- لا توجد مدفوعات أو محافظ أو خدمات مالية داخل التطبيق.
- المحتوى الإسلامي الأساسي مجاني.
- كل مادة شرعية قابلة للتتبع إلى مصدر واضح.
- لا تُعرض الفتوى على أنها جواب آلي نهائي.
- الخصوصية وتقليل البيانات مبدآن أساسيان.
- العمل دون اتصال قدر الإمكان.
- التصميم Mobile-first وRTL.

## الوحدات المستهدفة
1. القرآن: القراءة، البحث، العلامات، آخر قراءة، الاستماع.
2. الأذكار والأدعية: الصباح والمساء وما بعد الصلاة والمناسبات.
3. الحديث: مجموعات موثقة مع المصدر والدرجة عند توفرها.
4. الصلاة: مواقيت حسب الموقع/المدينة، التنبيهات، القبلة.
5. العبادة: متابعة شخصية اختيارية محليًا.
6. السبحة: عداد محلي بسيط.
7. التعلم: مسارات قصيرة ومواد منظمة.
8. الأسرة والأطفال: محتوى تعليمي مناسب للعمر.
9. البحث الموحد: بحث سريع في المحتوى المنشور.
10. الإعدادات والخصوصية: التحكم في الموقع والإشعارات والتخزين.

## مراحل التنفيذ
### المرحلة 1 — الأساس
- فصل الواجهة عن المحتوى.
- تقسيم JavaScript إلى وحدات.
- تثبيت نموذج الحالة المحلية.
- اختبارات smoke وlint وفحص الأسرار.

### المرحلة 2 — المحتوى
- نقل البيانات إلى ملفات JSON منظمة.
- إضافة metadata للمصادر.
- إضافة بحث وفهرسة محلية.
- إضافة نظام مراجعة قبل النشر.

### المرحلة 3 — تجربة التطبيق
- تحسين PWA والتثبيت والعمل دون اتصال.
- تحسين الوصولية والأداء.
- دعم الإشعارات بإذن صريح.
- تحسين RTL والشاشات الصغيرة.

### المرحلة 4 — التوسع
- مزودات قابلة للاستبدال لمواقيت الصلاة والصوت.
- مزامنة اختيارية فقط عند الحاجة.
- Backend اختياري للمحتوى المنشور، دون جعل الحساب شرطًا للاستخدام الأساسي.

## الاستدامة
التطبيق مجاني للمستخدم. أي دخل مستقبلي يجب أن يكون منفصلًا عن إتاحة المحتوى الإسلامي الأساسي وألا يحول العبادة أو النصوص الشرعية إلى خدمة مدفوعة.
