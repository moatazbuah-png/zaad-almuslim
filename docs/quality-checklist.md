# قائمة فحص الجودة

## المحتوى الشرعي

- [ ] المصدر الأصلي محدد.
- [ ] المؤلف أو الجهة مسجلان.
- [ ] النص مراجع لغويًا.
- [ ] درجة الحديث موضحة عند الحاجة.
- [ ] الرأي الفقهي مميز عن النص المنقول.
- [ ] تاريخ المراجعة مسجل.

## الإصدار التقني

- [ ] تعمل الواجهة على الهاتف وسطح المكتب.
- [ ] تعمل اللغة العربية والاتجاه RTL.
- [ ] لا توجد أخطاء JavaScript في Console.
- [ ] تعمل أزرار التنقل والنسخ والعدادات.
- [ ] لا توجد مفاتيح سرية في المستودع.
- [ ] تم اختبار المشروع عبر خادم محلي.

## إمكانية الوصول

- [ ] للأزرار أسماء واضحة.
- [ ] الألوان ليست وسيلة التمييز الوحيدة.
- [ ] النص قابل للقراءة على الشاشات الصغيرة.
- [ ] النوافذ المنبثقة قابلة للإغلاق.
