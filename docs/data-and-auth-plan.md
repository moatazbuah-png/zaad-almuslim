# خطة البيانات والمستخدمين

## ما تم بناؤه

- `data/content.json`: مصدر بيانات أولي للسور والأذكار والأحاديث.
- `admin.html`: لوحة إدارة محلية للبحث والإحصاءات وحفظ المسودات.
- `admin.js`: منطق اللوحة مع `localStorage`.

## حدود النسخة الحالية

هذه لوحة تجريبية تعمل داخل المتصفح فقط. لا يوجد فيها تسجيل دخول حقيقي أو نشر مركزي أو صلاحيات آمنة.

## الانتقال إلى الإنتاج

1. إنشاء API خلفي.
2. استخدام قاعدة بيانات PostgreSQL أو خدمة موثوقة.
3. إضافة تسجيل دخول آمن وجلسات قصيرة العمر.
4. إضافة أدوار: مدير، محرر، مراجع شرعي، قارئ.
5. منع نشر المادة إلا بعد اعتماد المراجع.
6. تسجيل سجل تغييرات Audit Log.
7. حماية بيانات الأطفال والمستخدمين.
8. حفظ الأسرار في متغيرات بيئة لا في المستودع.

## نموذج الجداول

- `users`
- `roles`
- `content_items`
- `content_sources`
- `review_events`
- `user_progress`
- `user_preferences`
- `audit_logs`

## البحث

النسخة الحالية تستخدم بحثًا نصيًا في المتصفح. عند زيادة المحتوى، ينقل البحث إلى فهرس مخصص يدعم العربية والبحث الدلالي، مع عرض المصدر دائمًا.
