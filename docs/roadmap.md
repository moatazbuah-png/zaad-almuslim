# خارطة طريق زاد المسلم

## المرحلة 1 — MVP الحالي

- واجهة عربية RTL متجاوبة.
- القرآن والأذكار والحديث.
- السبحة والمتابعة اليومية.
- مواقيت الصلاة التجريبية والمدينة والاستماع.
- هوية بصرية إسلامية موحدة.

## المرحلة 2 — المحتوى الموثق

- إكمال بيانات السور والآيات.
- إضافة مصادر الحديث والتخريج ودرجات الأحاديث.
- تصنيف الفقه والتفسير والعقيدة والسيرة.
- إضافة مصدر وتاريخ تحديث لكل مادة.

## المرحلة 3 — الحساب ولوحة الإدارة

- تسجيل المستخدمين.
- حفظ التقدم والتفضيلات.
- لوحة إدارة للمحتوى والمراجعة.
- أدوار للمحرر والمراجع الشرعي والمدير.

## المرحلة 4 — التعليم والأسرة

- دورات ومسارات تعليمية واختبارات.
- قسم الأسرة والأطفال.
- قصص تفاعلية وتلعيب آمن.
- شهادات إتمام غير أكاديمية مع توضيح طبيعتها.

## المرحلة 5 — التكامل المؤسسي

- معايير بيانات موحدة.
- ربط المصادر والمؤسسات المرخصة.
- بوابة المعرفة والبيانات المفتوحة.
- فصل المحتوى الرسمي عن الرأي والتحليل.

## المرحلة 6 — الاقتصاد والعمل الإنساني

- دليل الشركات والأسواق.
- الحلال والمعايير.
- المشاريع والتبرعات والتقارير.
- تتبع الشفافية دون نشر بيانات المستفيدين الحساسة.

## المرحلة 7 — الذكاء الاصطناعي

- البحث الدلالي.
- تفريغ الصوت والبحث داخل الفيديو.
- الترجمة والتلخيص.
- مساعد معرفي يعرض المصادر ولا يصدر فتوى مستقلة.

## معايير القبول

- لا ينشر المحتوى الشرعي الحساس دون مراجعة.
- كل مصدر له جهة وتاريخ وحالة تحديث.
- حماية بيانات الأطفال والمستخدمين.
- لا تُعرض الأقوال الفقهية المختلفة باعتبارها قولًا واحدًا.
- كل تكامل خارجي يستخدم API موثقًا ومصرحًا به.
