# زاد المسلم 🕌

منظومة إسلامية رقمية عربية، مجانية للمستخدم، تجمع أدوات العبادة والمعرفة في تجربة سريعة تعمل على الويب والموبايل.

## المبدأ
المحتوى الإسلامي الأساسي مجاني. لا توجد داخل المنتج محافظ أو تحويلات أو اشتراكات مالية. الاستدامة التجارية، إن أضيفت لاحقًا، تكون منفصلة عن إتاحة المحتوى الأساسي.

## الوحدات
- القرآن والقراءة والمتابعة والعلامات.
- الأذكار والأدعية.
- الحديث مع المصدر والمرجع وحالة المراجعة.
- مواقيت الصلاة والقبلة.
- السبحة والمتابعة الشخصية محليًا.
- البحث والتعليم.
- PWA والعمل دون اتصال قدر الإمكان.

## الجودة
المحتوى الديني يمر بدورة: `draft → review → published → archived`، ولا يُنسب نص ديني دون مصدر قابل للتتبع.

## التطوير
راجع `docs/product-blueprint.md` و`docs/architecture.md` و`docs/content-policy.md` لفهم المنتج والمعمارية وسياسة المحتوى.

## تشغيل محلي
يمكن تشغيل المشروع كملفات ثابتة عبر أي خادم محلي، لأن Service Worker لا يعمل من `file://` في المتصفحات الحديثة.

## الحالة
المشروع في مرحلة تقوية الـMVP والتحضير للإصدار الإنتاجي. يتم التطوير تدريجيًا مع الحفاظ على الوظائف الحالية.
