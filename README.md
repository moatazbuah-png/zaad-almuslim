# زاد المسلم

زاد المسلم هو مشروع إسلامي رقمي كامل منطلق من فكرة بناء منظومة إسلامية متكاملة تجمع بين المعرفة الشرعية والتعليم والخدمات الرقمية والهوية الإسلامية في واجهة واحدة متكاملة.

## الحالة الحالية

المشروع الآن في مرحلة MVP قوية ومكتملة من الناحية الأساسية، وتشتمل على:
- واجهة عربية RTL احترافية
- صفحة رئيسية عربية متكاملة
- آية اليوم
- حديث اليوم
- أذكار الصباح والمساء والنوم
- سبحة إلكترونية
- متابعة العبادات اليومية
- شعار ومنظومة مؤسسية متكاملة

## الهدف العام

بناء منظومة إسلامية رقمية موحدة تربط:
- القرآن والحديث
- الفقه والعقيدة
- الأذكار والعبادات
- التعليم
- الأسرة والأطفال
- الاقتصاد الإسلامي
- الحلال والمعايير
- العمل الإنساني
- الذكاء الاصطناعي والبيانات

## التشغيل

يمكن تشغيل المشروع مباشرة من المتصفح، أو عبر خادم محلي:

```bash
python -m http.server 8000
```

ثم زيارة:

```text
http://localhost:8000
```

## الخطة القادمة

### المرحلة الأولى
- تقسيم الصفحات إلى: القرآن، الأذكار، الحديث، المتابعة
- تحسين التكامل بين الأقسام
- إضافة محتوى موسوعي أكبر

### المرحلة الثانية
- لوحة تحكم جديدة لإدارة المحتوى
- قسم التعليم والتطبيقات
- إضافة نظام البحث داخل القرآن
- إضافة قاعدة بيانات للمحتوى

### المرحلة الثالثة
- المنظومة الاقتصادية
- الحلال والمعايير
- الأسرة والأطفال
- العمل الإنساني
- تطوير الذكاء الاصطناعي

## القيم الأساسية

- التوثيق العلمي
- احترام الاختصاص الشرعي
- عرض الخلاف بنزاهة
- الالتزام بالهوية الإسلامية
- جودة المحتوى
- تجربة مستخدم سهلة وواضحة

## الخلاصة

هذا المشروع الآن جاهز كتجربة أولية قوية، وهو قاعدية استراتيجية لبناء منظومة إسلامية رقمية موحدة تشمل كل محاور المعرفة والخدمة والبيانات والمؤسسات.
