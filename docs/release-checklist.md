# قائمة إصدار زاد المسلم

## المنتج
- [ ] القرآن والأذكار والحديث يعملون دون أخطاء.
- [ ] كل محتوى منشور يملك مصدرًا ومرجعًا مناسبًا.
- [ ] لا توجد خصائص مالية داخل التطبيق.
- [ ] المحتوى الأساسي متاح مجانًا.

## التقنية
- [ ] Service Worker يثبت ويحدث بنجاح.
- [ ] التطبيق يعمل بعد انقطاع الشبكة.
- [ ] بيانات المستخدم المحلية لا تضيع بعد التحديث.
- [ ] لا توجد مفاتيح أو أسرار داخل المستودع.
- [ ] الاختبارات الآلية تمر.
- [ ] Console errors = 0 في المسارات الأساسية.

## الوصولية والأداء
- [ ] RTL صحيح.
- [ ] التنقل بلوحة المفاتيح ممكن حيث يلزم.
- [ ] عناصر الأزرار تحمل أسماء واضحة لقارئات الشاشة.
- [ ] reduced-motion محترم.
- [ ] الصور والأصول مضغوطة.

## النشر
- [ ] اسم التطبيق وأيقونته ولقطات الشاشة جاهزة.
- [ ] سياسة الخصوصية منشورة.
- [ ] روابط الدعم تعمل.
- [ ] رقم الإصدار محدّث.
- [ ] اختبار على Android وشاشات صغيرة وكبيرة.
