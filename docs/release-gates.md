# بوابات الإصدار

لا تعتبر النسخة جاهزة للإصدار إلا بعد اجتياز جميع البوابات:

1. **المحتوى:** كل مادة دينية منشورة لها مصدر ومرجع وحالة مراجعة مناسبة.
2. **الوظائف:** القرآن، الأذكار، الحديث، البحث، الصلاة، الإعدادات، والحفظ تعمل دون أخطاء حرجة.
3. **البيانات:** لا توجد مفاتيح سرية أو بيانات شخصية ثابتة داخل المستودع.
4. **PWA:** manifest وservice worker والتحديثات والعمل دون اتصال الأساسي تعمل.
5. **الوصولية:** التنقل باللمس ولوحة المفاتيح، حالات التركيز، أسماء عناصر التحكم، والتباين مقبولة.
6. **الأداء:** لا يتم تحميل مكتبات أو بيانات ضخمة بلا حاجة، وتُؤجل الميزات غير الضرورية.
7. **الخصوصية:** الموقع والإشعارات اختياريان، ولا يتم طلبهما دون حاجة واضحة.
8. **الأمان:** لا يتم تنفيذ HTML غير موثوق أو إدخال مستخدم على أنه كود.
9. **التوافق:** اختبار Chrome Android على الأقل، ثم اختبار متصفحات سطح المكتب الرئيسية.
10. **النشر:** إنشاء نسخة إصدار منفصلة بعد اجتياز البوابات، مع rollback واضح.
