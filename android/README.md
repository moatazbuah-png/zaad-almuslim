# MISHKAT Android

The web/PWA app is the source UI. This directory documents the Android packaging contract.

## Build prerequisites

- Android Studio / Android SDK
- JDK 17
- Gradle wrapper generated by the Android project
- Application id: `com.mishkat.islamic`

## Validation

The repository workflow `.github/workflows/android-emulator.yml` runs the Android emulator smoke test once a native Gradle project is present.

Do not claim Android release readiness until an APK/AAB is built and the emulator smoke test passes.
